提交社区插件

首次投稿请填写公开 GitHub 仓库链接、发行包附件下载链接和一句话介绍。仓库内的 PNG 图标链接可选。

用 WhaleLife 打包工具生成 .wlpkg.gz，上传到自己仓库对应版本的正式 GitHub Release，复制该附件的下载链接。在发行说明中列出附件字节数、SHA-256、适用的 WhaleLife 版本、系统、架构及必需插件版本。打包命令与格式说明

尚未提供发行包的投稿在原 Issue 待补件，补上链接并通过审核后收录。已有的手动安装条目继续提供「安装说明」。

已收录插件发新版后，请在主仓提交新版复审，填写仓库、完整插件 ID、版本、Release 和附件链接。同一版本已有开放审核帖时在该帖补充。

只换图标可单独提交图标审核，无需重新打包。
